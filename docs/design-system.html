Mountains Design System

Mountain companion app for tracking speed, distance, routes, and vertical drops in real time. All values follow a strict 4px grid — every spacing, sizing, and positioning value is a multiple of 4.

Rules

Non-negotiable constraints from design.md.

  • 4px grid. Every spacing, sizing, and positioning value must be a multiple of 4. No 6px, 10px padding, no 22px height (correct to 24px), no 46px height (off-grid — flag it).
  • No opacity text on dark backgrounds. Text on photo backgrounds uses #D5F4FC (primary) or #BBE2EC (secondary) as solid tokens — never invented rgba values like rgba(213,244,252,0.55).
  • No tab bar. The app has no bottom navigation tab bar. All navigation lives in the 3 header icon buttons (Friends, Chat, Avatar), consistent across every screen.
  • Type scale rule. Only sizes in the scale exist: 38, 20, 18, 17, 16, 12, 10px. Sizes like 11, 13, 14, 15px are not valid in this system.
  • Icon color. Fluent UI icons are always #D5F4FC (light blue) — never white (#ffffff).
  • Figma asset URLs expire in 7 days. Download and host assets locally before building. Use curl -sLk {url} -o file.ext then check type with file command — many arrive as SVG despite a .png extension.
  • Button size system unresolved. Current screens have at least 3 inconsistent heights (40, 44, 46px). Flag instances and standardise before production.
