Setup

Run Locally

No install needed. Requires Node.js. Serve from the project root so all assets/ paths resolve correctly.

# Clone the repo git clone https://github.com/{username}/{repo}.git cd {repo} # Start the preview server (port 4321) npx serve . -p 4321 # Open in browser http://localhost:4321 ← this page http://localhost:4321/docs/design-system.html

The dev server config is already in .claude/launch.json — Claude Code users can start it with preview_start from within a session.

Stack

  • HTML / CSS — no framework, no build step
  • Archivo Expanded — Google Fonts, 400 & 700 only
  • Fluent UI Icons — via Iconify CDN (fluent:{name}-24-filled)
  • 4px grid — every size and spacing is a multiple of 4
  • Figma MCP — Claude Code integration for asset export

Branching

main │ ├── feature/screen-{name} ├── feature/tokens-{change} └── fix/{description}

main is always deployable. Only merge when a screen is complete and reviewed.

Key Rules

  • All spacing/sizing = multiples of 4
  • Text on dark bg = solid tokens only, never rgba
  • Icons always #D5F4FC, never white
  • No tab bar — nav lives in the header
  • Type sizes: 38, 20, 18, 17, 16, 12, 10px only
